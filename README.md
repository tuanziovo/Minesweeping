# Minesweeping

一个用原生 HTML / Canvas 写的 Material Design 3 风格扫雷，打开网页就能玩。

**在线试玩：[https://tuanziovo.github.io/Minesweeping/](https://tuanziovo.github.io/Minesweeping/)**

## 特色

- **经典与无猜**：传统随机布雷，以及基于求解器的无猜模式（可自己调生成时限）。
- **多种玩法**：简单 / 中等 / 困难 / 自定义（最大 100×100）/ 自适应屏幕，外加每日挑战和 8 关战役。
- **手感与细节**：移动端支持双指缩放、拖拽平移和长按插旗；桌面端支持左/右/中键快开与全键盘操作。
- **主题配色**：浅色、深色、OLED 纯黑，12 套预设配色和自定义主色，数字支持色盲友好与高对比配色。
- **战绩与回放**：本地保存胜率、3BV / 3BV/s / IOE 数据和 10 个成就，历史记录支持进度拖拽和 0.5×–4× 倍速回放。

## 常用操作

- **手机**：点按翻开，长按插旗，双指缩放，单指拖动。
- **电脑**：左键翻开，右键插旗（可在设置里对调），中键或单击已翻开数字快开；键盘支持方向键、`Space`/`Enter`、`F`（插旗）、`H`（提示）、`R`（重开）、`Ctrl+Z`（撤销）、`Shift+F`（全屏）。
